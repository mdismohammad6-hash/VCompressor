# SkyCompressor 📦

**SkyCompressor** is a high-performance and lightweight Minecraft server plugin designed to optimize item and block storage by allowing efficient compression. It ensures smooth gameplay without causing any server lag.

---

## ✨ Features
- **Fast & Efficient:** Instant item and block compression with zero noticeable server lag.
- **Custom Recipes:** Fully configurable custom crafting recipes.
- **Lightweight Design:** Optimized for modern Paper/Spigot servers with minimal resource usage.
- **Easy Configuration:** Simple setup and easy-to-use configuration files.

---

## 📥 Installation
1. Download the latest `.jar` file from the [Releases](../../releases) tab.
2. Drag and drop the file into your server's `plugins` folder.
3. Restart your server or use a plugin manager to load it.
4. Configure the plugin to fit your server's needs in the generated config folder.
